API ENDPOINTS · ขาเข้า

            
จัดการรับข้อมูลเข้า (Incoming)

            
กำหนด URL และ Method เลือกผู้ใช้เดิมที่อนุญาตให้ส่งข้อมูล แล้วตรวจ JSON ที่ได้รับจากประวัติด้านล่าง

            
รับ JSON → ตรวจสิทธิ์ผู้ใช้ → บันทึก Logเก็บ headers และ body พร้อมซ่อนรหัสผ่าน · ขนาดสูงสุด 2 MB ต่อคำขอ

            

            

            

              URL ขารับทั้งหมด
              
ชื่อ / URLMethodผู้ใช้ที่อนุญาตสถานะรับล่าสุดจัดการ

              
            

            

              
เพิ่ม URL ขารับ

              

                
                
                
                ใช้เส้นทาง Production /procure/incoming/ ตามด้วยชื่อขารับ เช่น irV1 หรือ contract
                

                  

                  

                

                ระบบภายนอกต้อง Login ด้วยผู้ใช้ที่เลือก แล้วส่ง token ใน Header: Authorization: Bearer <token> โดยไม่ต้องใส่ username/password ใน body
                
                

              

            

            

              
ตัวอย่างการส่งข้อมูล

              ตัวอย่างด้านล่างแยก headers และ body เพื่อให้อ่านง่าย ตอนส่งจริงให้นำ headers ไปใส่ HTTP Header และส่งเฉพาะค่าใน body เป็น JSON
              

            

            
ประวัติ JSON ที่รับเข้ามา
แสดงทั้งคำขอที่สำเร็จและที่ถูกปฏิเสธสำหรับ URL ที่ตั้งค่าไว้ ครั้งละ 50 รายการ
