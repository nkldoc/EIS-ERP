ตรวจ field บังคับก่อน INSERT

เมื่อเลือก sp_tor_period_bill และ sp_tor_period_bill_receive พร้อมกัน ระบบยืนยันจะ UPDATE งวดหลักที่ตรงกับ pr_id + po_id + period_id ตาม mapper หรือ INSERT ใหม่เมื่อไม่พบ โดยใช้ข้อมูล root และใช้ ID ที่สร้างให้รายการ line_ids ทุกแถวโดยอัตโนมัติ ไม่ต้อง mapping sp_tor_period_bill_id เอง • ตรวจ NOT NULL ที่ไม่มี default แยกตามตาราง และตรวจค่าทุกแถวที่ mapping ไว้ โดยไม่นับ identity / computed / คอลัมน์ที่ระบบสร้างเอง ค่า 0 และ false ใช้ได้ ส่วนข้อความว่างในคอลัมน์ NOT NULL จะให้แก้ไขก่อนสร้าง SQL

ผลตรวจนี้ยังไม่ครอบคลุม foreign key, unique, check constraint และ trigger — หน้านี้สร้าง SQL preview เท่านั้น
